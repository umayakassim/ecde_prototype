# KEMIS ECDE Module – Clickable Prototype

Open `index.html` in a browser.

Prototype screens:
- ECDE Dashboard
- Learner Search / duplicate prevention
- 5-step ECDE enrolment workflow
- Learner biodata and automatic age calculation
- Parent/guardian information
- Residence
- ECDE enrolment details
- Confirmation and demo submission
- Learner list
- ECDE → Grade 1 transition workflow

This is a front-end prototype only; it does not connect to KEMIS, a database, authentication, or live Ministry reference data.
